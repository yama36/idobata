# 学校向けセットアップ（いどばたディスカッション）

このドキュメントでは、いどばたディスカッション（いどばたビジョン）を中学校などの授業で利用する際のセットアップのポイントを説明します。

## デフォルトについて

本システムは、授業などでそのまま利用しやすいよう、**政治的な文言を出さない中立的なデフォルト**になっています。

- サイトのデフォルト名は「みんなの対話の場」です
- 「このサイトについて」の説明文も、話し合い・意見をまとめる場としての説明のみです
- 管理画面から、授業名や学級に合わせて自由に変更できます

## 授業用に設定を変える手順

1. **管理画面にログイン**  
   開発環境の場合は [開発環境構築ガイド](./development-setup.md) に従ってアプリを起動し、管理画面の URL にアクセスします。

2. **サイト設定を開く**  
   管理画面内の「サイト設定」などから、サイト名と「このサイトについて」の内容を編集できます。

3. **授業用のタイトル・説明を入力**  
   - **サイト名**: 例）「〇〇中学校 3年1組 話し合いの場」「総合的な学習の時間 意見共有」
   - **このサイトについて**: 授業の目的や、生徒への参加の呼びかけなどを書くとよいです。

4. **テーマ（お題）を登録**  
   「テーマ」で議論したいお題を追加します。授業の単元や学級会の議題に合わせて設定してください。

## 授業で使えるテーマ例

- どうすれば、クラスみんなが過ごしやすい教室にできるか？
- どうすれば、地域の防災や安心・安全について、私たちにできることを考えられるか？
- どうすれば、環境にやさしいくらしを、学校や地域で進めていけるか？
- どうすれば、若者が安心してキャリアを築き、将来に希望を持てるようにできるか？

総合的な学習の時間、道徳、学級会など、話し合いや意見の整理が必要な場面で利用できます。

## 運用の流れ

1. 先生がテーマを設定する
2. 生徒がチャット形式で意見や質問を投稿する
3. システムが重要な論点を抽出し、「重要論点」として表示する
4. 必要に応じてレポートやまとめを生成し、振り返りや次の活動に活用する

詳細な機能の使い方は、[いどばた新分析システム 使い方ガイド](../idea-discussion/README.md) もあわせてご参照ください。
